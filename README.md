# ACADSYNC Analytics

ACADSYNC Analytics is a student attendance, activity, task and performance monitoring system.

## Features

- Student management
- Student attendance tracking
- Staff dashboard
- Admin dashboard
- Task management
- Student performance monitoring
- Activity tracking
- Performance score management
- Web-based dashboard

## Technologies

- Python
- Flask
- SQLite
- HTML
- CSS
- JavaScript
